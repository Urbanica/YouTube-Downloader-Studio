# История изменений

## [1.0.5] - 2026-10-17

### Добавлено
- Встроенное окно входа в YouTube на WebView2: можно авторизоваться в приложении без запуска Chrome или Brave.
- Сохранение сессии входа в пользовательской папке Windows; импорт `cookies.txt` оставлен как запасной вариант.

### Исправлено
- Повтор загрузки после HTTP 403 сохраняет выбранные cookies и снижает число потоков до одного.
- Ошибки YouTube и отклонённой авторизации отображаются более понятно.
- UI-обновления из фоновых задач передаются в главный поток приложения.

### Сборка и публикация
- GitHub Actions собирает Windows EXE и публикует его как Latest Release при отправке тега `v1.0.5`.
